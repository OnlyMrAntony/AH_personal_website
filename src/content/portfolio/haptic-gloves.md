# Haptic Navigation Gloves

## Overview
A wearable hardware prototype designed to assist navigation through directional tactile vibration feedback.

## Key Technical Details
* Built using microcontrollers and precision vibration motors.
* Programmed hardware timing logic for spatial feedback cues.
* Awarded **1st Place** at the LIFETank Capstone Competition.
